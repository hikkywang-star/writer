📤 批次匯出到 Buffer

Buffer 沒有內建 30 篇一次貼上的欄位，所以這裡準備兩種送進去的方式，看妳那邊 Buffer 方案支援哪種：

① 逐篇貼上（最穩定）
左側清單每篇都有「複製」按鈕，按一下複製、切到 Buffer 貼上、排時間，再回來按下一篇。中間可以隨時關掉分頁，進度會留著。
② Buffer 官方「Bulk Upload」一次匯入
Buffer 有內建批次上傳功能：Publish → 選頻道 → 右上角⚙️設定 → General → Bulk Upload，免費版一次最多10篇、付費版最多100篇。下載下面的 .csv，直接拖進去上傳即可，欄位已完全對齊 Buffer 官方範本（Text / Image URL / Tags / Posting Time 四欄、每欄都加雙引號）。
發 IG 一定要有圖片網址：先在每篇下方「🖼️ IG 圖卡」下載4張JPG（或按頂部一次打包30天、120張），挑一張上傳到 Imgur／Google Drive 公開空間，把連結貼回每篇的圖片網址欄，CSV 才會自動帶上 Image URL 欄位。Tags／Posting Time 欄位會留空給妳自己在 Buffer 裡填，因為 Tags 必須是妳頻道已存在的標籤、Posting Time 則建議直接用 Buffer 排程比較準。
③ 逐篇複製版（.txt）
每篇之間清楚標出 Day 幾，開啟檔案就能一篇一篇選取、複製、貼到 Buffer 的貼文框，不想用 CSV 匯入的話這個最直覺。
🤖 批次生成 Prompt（含妳的語氣範本）

先在左側清單把 30 天的「主題」填一填（可以空著讓 AI 自由發揮），複製下方 Prompt 貼給 AI（Gemini／ChatGPT／Claude 都可以），把回傳的 JSON 貼回下面「貼上 AI 生成內容」就會自動分配到 30 天。

📥 貼上 AI 生成內容

貼上 AI 回傳的 JSON（[{day, topic, content}, ...]），會自動依 day 分配進 30 天清單，原本已經寫的內容才不會被亂蓋掉。

♻️ 舊文回收區

這裡是完全獨立的第二個區域，跟上面 30 天的排程互不相干——貼進來的舊文不會覆蓋、也不會取代任何一天的內容。把以前發過的舊文貼在下面，每篇之間用一行只有 --- 的分隔線隔開。每篇第一行如果是 圖:網址（例：圖:https://example.com/photo.jpg），會自動抓成該篇的圖片網址，其餘部分當作內文。解析好之後可以在下面直接編輯，最後按「⬇️ 匯出回收區 Buffer CSV」，就能單獨拿這批舊文去 Buffer 批次上傳，跟 30 天的 CSV 是分開的兩份檔案。
